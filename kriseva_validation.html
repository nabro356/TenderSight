Architecture Proof

Local-first, at a high level.

The architecture proof is intentionally high-level. It shows that local storage, local document processing, and local model routes (where configured) are the design defaults, and that external connectors are explicit.

  • Local file storage and local database for tender bundles.
  • Local document parsing for PDF, DOCX, XLSX, TXT, CSV.
  • Local OCR routing for scanned / low-text PDFs.
  • Local model routes available where configured.
  • Explicit external boundary; no silent network calls.

See the security page for boundary detail.

Test Status

Careful test wording, intentionally.

CAREFUL WORDING · NOT A MARKETING HEADLINE § 03 / VALIDATION

A recent internal repo inspection reported 4,072 pytest-collected tests and a passing fast test run. Full verification status should be reviewed before using this as a headline production-readiness claim.

The number above is repo-inspection telemetry, not a marketing headline. It does not appear on the homepage. Public production-readiness claims require auth, tenant isolation, security hardening, and a deployment audit that have not been completed.
